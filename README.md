# Multi-Modal Emotion Detection System with AI Therapy Suggestions

## Overview

An AI-powered Multi-Modal Emotion Detection System capable of analyzing emotions from:

* Facial Images
* Live Webcam Feed
* Speech/Audio Input
* Text Input

The system combines Computer Vision, Natural Language Processing, Deep Learning, and Conversational AI to provide emotion-aware responses and micro-therapy suggestions.

---

## Features

### Emotion Detection from Images

* CNN-based Facial Emotion Recognition
* Real-time emotion prediction
* Support for multiple emotion classes

### Emotion Detection from Audio

* Speech emotion analysis
* Emotion classification from voice recordings

### Emotion Detection from Text

* NLP and LSTM-based sentiment/emotion analysis
* Context-aware emotion prediction

### AI Chatbot Integration

* Interactive chatbot
* Emotion-aware responses
* Personalized conversation flow

### Micro-Therapy Suggestions

* Mental wellness recommendations
* Positive reinforcement messages
* Emotional support suggestions

### User Management

* Registration and Login
* Profile Management
* Emotion History Tracking
